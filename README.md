# Product — Single Product COD Landing Page

Mobile-first single-product e-commerce landing page for Bangladesh.

## Live
GitHub Pages: https://spdc-info.github.io/Product-/

## Features
- Product offer and pricing
- Cash on Delivery order form
- Bangladesh division/district selection
- Delivery and total calculation
- Responsive mobile-first UI
- Basic client-side validation

## Backend
The current demo is frontend-only. Connect the order form to a Google Apps Script Web App + Google Sheets before production use.
